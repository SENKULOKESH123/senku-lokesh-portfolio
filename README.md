# Senku Lokesh — Portfolio

A responsive React + Vite personal portfolio built from the information in the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

This is a standard Vite app and can be deployed to Netlify, Vercel, GitHub Pages, or another static host.

## Important

Update the project GitHub link for the Infosys project when a public repository is available.
